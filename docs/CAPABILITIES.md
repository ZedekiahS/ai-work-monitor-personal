# 接入能力与可观察范围

本机 JSONL 和 SQLite 来源以只读方式观察。任务与子 Agent 的历史、关系、轮次、用量、回放、搜索、备注和收藏依据实际落盘字段；没有证据的状态显示未知。明确终态不会被旧回调重新改为运行。静默不等于完成或离线。

额度查询使用独立 Codex App Server 只读账号接口，包含超时、退避和后台周期刷新；不调用任务启动、账号切换、登录或认证刷新。独立探针不能证明其他桌面实例中的任务状态。来源没有稳定账号 ID 时显示未确认；用户可限定来源和时间绑定。账号切换后受影响的共享暂停，需重新确认。

额度百分比按账号、池和窗口独立显示；缺失为未知，同一账号多设备观察不相加。Token 统计遵循 `USAGE_RECONCILIATION.md`，不等同供应商结算账单。Hooks 默认关闭，详见 `HOOKS.md`。真实客户端版本和事件覆盖应在目标电脑核验。

`npm run diagnose` 生成脱敏结构诊断，不保存对话、凭据、会话标识或完整路径。诊断不是现场全生命周期验收。Windows 桌面关闭窗口继续托盘运行，选择退出才停止本产品采集。个人同步服务与企业连接都是可选项，本机个人功能不依赖它们。

本仓库不包含个人实测记录。第二台电脑、真实 Hooks、通知、生产证书和公司网络应按 `SECOND_DEVICE.md` 分别验收。
