## 原机开发窗口真实验证

2026-11-15，Computer Use 操作构建目录的原生EXE：

- 实际显示当前Codex来源的22%周余额和重置时间；不是合成额度。
- 点击水球展开、置顶关闭再开启、动态关闭、缩小至90%均已观察；设置文件反映相应选择。
- 用户报告初版拖动不跟随；修复为鼠标和窗口统一物理像素坐标后，用户确认“现在跟随正常，只有一个球”。保留失败记录，不把初版记为通过。
- 最初两个球来自验收在正常桌面和隔离执行环境分别启动了实例。关闭这两个测试进程后，只用正常桌面入口；重复启动仍是同一窗口，进程核对只有一个。未把跨隔离命名对象命名空间当成真实普通桌面双实例测试。
- 用户手动右键托盘退出后，执行方核对该候选路径的进程数为0。这是真实用户鼠标退出证据；前面的强制停止测试实例不计为托盘验收。
- 短时资源抽样：展开、动态关闭时工作集约198.9 MiB、私有内存约175.5 MiB，10秒CPU增量0秒。此为单机短时样本，未包含Codex探针峰值，不能宣传原生包小就等于低内存。长时间资源占用仍待测。

上述窗口验收发生在最终固定提交之前。之后收尾包含退出等待、隐藏时减少UI更新、未知状态文字和安装打包配置；不能把开发窗口证据冒充最终安装包的所有功能已经实测。

## 安装与恢复

先从托盘退出原生额度窗，再运行上述安装器，使用默认目录 `%LOCALAPPDATA%/Programs/AI Quota Window Native`；从开始菜单“AI 额度窗（原生版）”打开。旧Electron版不自动卸载，避免同时启动两个不同产品。

本产品仅保存 `%APPDATA%/ai-quota-window-native/settings.json`。损坏设置会保留带 `.damaged-时间` 后缀的原文件再恢复默认。卸载保留设置，不删除Monitor或Codex目录。需要恢复窗口设置时，先退出原生版，备份当前settings.json后再复制本产品的设置备份；无需也不应复制Monitor数据库、设备身份或Codex凭据。要恢复旧Electron版，直接使用它原有入口。
