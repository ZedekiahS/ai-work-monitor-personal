# 隐私、授权与删除

默认个人离线模式不需要中心账号，也不会向公司发送数据。可选 Hooks 默认关闭。原有 Codex 登录令牌留在 Codex 原有边界，额度读取通过客户端只读接口；产品从不复制 auth.json，不把 AI 登录材料送到中心。

## 本机保存

本产品数据库保存来源指纹、线程/回合/Agent 关系、事件时间、模型、可采集 Token、额度快照、账号散列标识、项目映射、备注和已采集的部分消息文本。打开旧会话时可按需只读源数据库中的用户/助手文本，工具参数、输出和加密内容不读。正文以不可信纯文本渲染。

本地数据目录及备份不是脱敏文件，可能含私人会话，按当前 Windows 用户权限保管。备份不得当作诊断包分享。产品凭据在 SQLite 中使用 AES-GCM 单独加密；Windows 桌面端用 Electron safeStorage/DPAPI 保护密钥并通过父子进程 IPC 解锁，不送到网页。命令行模式使用数据目录中的本地密钥文件，不等同 DPAPI。数据库其他个人记录不做整体加密，系统保护也不防止同一 Windows 用户下的恶意程序。来源文件不被本产品清理、改写或归档。

## 共享预览与真实载荷

只有以下固定集合能进入中心：provider、设备/环境/来源的产品 ID、会话/回合/Agent ID 和关系、已选择账号的匿名产品 ID、明确选择的项目 ID 与用户主动填写的共享别名、事件/观察时间、模型、状态与证据强度、Token 增量；单独勾选后才包含账号级额度池、窗口、剩余百分比及重置时间。修正事件额外包含被修正的事件 ID 和 CAS 版本。本机项目名称不会自动当作共享别名发送。

**不接受**正文、提示词、代码、工具参数/输出、完整路径、任务标题、AI 密钥/令牌、原始认证文件和未知自由字段。服务端白名单拒绝这些字段，不仅依赖客户端隐藏。共享预览与发送使用同一协议字段定义。

工作用量必须同时命中账号、项目和时间范围。账号额度是整体账号信息，可能反映私人使用；共享它不等于共享私人历史。账号额度与工作项目用量在中心保持独立。完整对话跨电脑同步未实现，远端只有元数据。

会话创建账号不自动作为每轮计费账号。若来源只有creator字段，按事件发生时间的人工绑定是共享前置条件；没有映射不发送。源日志额度缺少可证明的当前身份时保留未确认。撤销时间映射前，需先撤回相关共享并等待中心确认，以免旧归属的队列继续发送。

## 权限与撤回

产品用户、空间成员关系和 AI 账号分别建模。产品/设备 token 只授权各自角色和固定空间；客户端换 workspace_id 不能越权。员工管理、停用、退出、配对、设备撤销、授权、导出和审计均有服务端检查。viewer 无权导出或管理；member 不可看到其他员工私有范围。

撤回立即停止本地新上报、取消未发送队列，并请求中心删除该授权的可识别明细。断网时明确显示中心删除待确认；不承诺当场已从远端删除。旧目标凭据和删除游标独立，切换当前空间不改变撤回目的地。停用成员/撤销设备后，原设备 token 不能继续上传。

持久删除会话会写入最小 tombstone；重扫、恢复旧备份、迟到补传和新的 grant 都不能自动复活已删事件。中心到期清理同样留下最小事件标记。重建缓存保留删除标记；没有提供无提示清空 tombstone 的入口。

中心共享明细默认90天，可在授权预览时选择1–365天；过期数据在查询中立即排除，并定期删除。保留审计和删除标识用于防止重放，不保留对话正文。**管理员已经导出的文件无法追回。**

## 接口与诊断

本地 HTTP 只监听127.0.0.1，验证 Host、Origin 和每次启动凭据；Cookie 为 HttpOnly/SameSite Strict。请求大小受限，页面设置 CSP，路径打开与外链受限，不暴露 Codex 控制端口。跨机器中心要求 HTTPS，证书验证没有关闭。

诊断默认移除正文、代码、认证材料、真实账号标识和完整路径；导出前可在设置页预览。CSV/JSON 会话导出只含脱敏元数据，CSV 处理公式开头。导出使用快照分页读完所选范围，每页重新核验当前权限；原始事件含更正行，不得直接累加。

真实员工授权、多机网络与生产 TLS 部署尚未现场验收。现有策略与集成证据使用隔离测试用户和临时数据库，没有上传用户的真实 AI 历史。
