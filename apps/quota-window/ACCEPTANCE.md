# 纯余额版 0.1.0 验收记录

本轮将纯余额产品和 AI Usage Window 集成入口区分。独立产品只查询当前 Codex 登录账号额度，额度窗口、置顶、缩放/大小、动态效果、拖动和托盘属于本产品范围。

## 已执行

- TypeScript 构建和纯余额 UI 类型检查通过；核心回归 203/203；已有 UI 组件回归 22/22。纯余额协议回归验证只发送初始化、账号、额度三类请求，不查询累计 Token；单次并发、节流、登录变化、失败未知及自身子进程结束通过。
- 原生开发窗口实际显示真实剩余额度；点击展开可见额度详情和三个设置项（置顶、动态效果、大小），没有监控台入口。
- 实际鼠标关闭动态效果后设置文件出现 motion=false，再次开启后恢复 true。设置使用独立测试目录，未修改原监控数据库或配置。
