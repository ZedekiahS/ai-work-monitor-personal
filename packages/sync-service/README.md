# 本人同步服务

仅本人身份、本人设备和明确授权的元数据。无邀请员工、成员管理、公司租户权限或跨员工报表。不接受 AI 密钥或完整对话。

Node 24+ 与 PostgreSQL 18。公开候选根运行 `npm ci`、`npm run build:protocol`，然后 `npm ci --prefix packages/sync-service`、`npm run build --prefix packages/sync-service`。设置 PERSONAL_DATABASE_URL 与独立的 SYNC_OWNER_TOKEN（至少 32 字符），`npm start --prefix packages/sync-service`。首次令牌仅用于建立本人产品身份，后续登录使用产品恢复码；不是供应商凭据。

默认 127.0.0.1:4321；远程必须有可验证的 TLS 证书。使用 compose.yaml 自行部署，证书与秘密由部署者提供，不写入源码。员工/个人电脑主动向服务发起 HTTPS，无需开放电脑入站端口。服务不提供托管承诺；断网时个人本机功能仍可用，跨电脑同步等待恢复网络。

数据备份：停止服务写入后或使用 PostgreSQL 一致性 `pg_dump` 备份数据库；恢复前先保存当前库，在同版本空库恢复并验证。保管恢复码，不复制一台电脑的 Monitor 数据库给另一台。

共享内核沿用现有协议、ACK、收件凭证、永久删除标记与用量更正实现；私有 Hub 通过锁定 npm tarball 依赖它。本包采用 MIT 许可证，版权署名为 ZedekiahS，完整条款见本目录 LICENSE。

## 0.2.0-candidate.2 接口与升级规则

所有接口仍使用产品凭据或独立设备凭据认证，协议事件版本维持 1。以下字段属于对应控制接口，不放入事件明细。

- `POST /v1/heartbeat`：`collectorHealth` 是必要的采集健康字段。新版客户端按每个连接持久保存并递增正安全整数 `heartbeatSeq`；服务端仅接受大于该设备已接收序号的更新。只有具备当前接收方的有效账号、项目与时间授权时，才发送 `taskState: "running"` 及 `taskActivity: { grantId, accountId, projectId, occurredAt }`。服务端再次检查权限；活动发生时间超出最近 15 秒或授权失效时，设备查询不会把旧活动显示为当前运行。当前接收方没有仍有效且未暂停的任务授权时，只发送健康与新序号，清除原活动；迟到的旧心跳不能覆盖清除。旧客户端不带序号的心跳不提供任务活动证明。断网情况下，不能声称已经即时清除远端状态。
- `POST /v1/self/register`：必须使用产品用户凭据。新版客户端在请求前持久保存 `registrationId` 及随机 32 字节的 base64url `registrationToken`，连同 `workspaceId`、`label`、`deviceId`、`environmentId` 提交。两项登记字段必须成对出现。相同用户、空间及登记 ID 的重复请求，在设备、环境和凭据一致时返回同一设备与凭据，不重复创建有效设备；服务端只保存凭据哈希。登记对应设备已撤销或凭据已轮换时返回 409，不恢复旧凭据。旧的不带登记字段调用保持兼容，但不具备这项重试幂等保证。
- 配对链接升级：新码明确记录产品用户或设备签发者；撤销设备会使该设备尚未消费的配对码失效。缺少签发证明的旧码在预览与兑换时返回 409，要求在已登录设备重新生成。此校验不删除旧记录，也不改写旧码的撤销或消费字段。产品用户签发的新码不会因其他设备撤销或服务重启而失效。设备凭据只能轮换或撤销自身，操作其他设备凭据需产品用户身份。

升级前执行 PostgreSQL 一致性备份并在隔离库验证恢复。公共增量迁移版本为 4，新增签发者证明、活动授权与心跳序号、幂等登记记录，保留既有用户、设备、事件、授权及删除标记。先升级服务，再升级客户端；重新生成旧版未用链接。恢复或回退必须保留最新撤回/删除状态；退回旧代码也会恢复旧版权限缺口，不能作为长期安全方案。
